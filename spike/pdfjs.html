pdf.js extraction spike — proves the browser text layer works from file://
Pick a PDF

Runs fully in the browser: pdf.js legacy build (main-thread "fake worker", no server, no worker file needed). Items are clustered into a pdftotext -layout-shaped string and passed through the SAME stitch/rules pipeline as the CLI (src/core/ladder-core.js). Measured on the corpus: equivalent field quality to the poppler path; PDFs with subset fonts pdf.js cannot decode simply yield fewer items — the server flow (ladder serve) covers those.
