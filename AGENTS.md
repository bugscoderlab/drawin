# drawin

Laddertech ladder-drawing toolkit: PDF → SVG conversion with a repair fallback
chain, text/geometry binding templates, scaffold + editor server, and an eval
scoreboard. See `wiki/` for the conversion pipeline and architecture notes.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in bugscoderlab/drawin via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
